# GLOSSARY

**Backpressure**\
A way to slow or reject incoming work when a consumer is at capacity.

**Bind**\
Ask the operating system to associate a local address and port with a socket.

**Body**\
Optional payload bytes after an HTTP message's header section.

**CRLF**\
Carriage return followed by line feed (`\r\n`), used as the HTTP/1.x line ending.

**Framing**\
The rules used to locate message boundaries within a byte stream.

**Header**\
A named HTTP metadata field such as `Content-Type` or `Host`.

**HTTP**\
An application protocol defining requests and responses.

**Keep-alive / persistent connection**\
Reusing one TCP connection for more than one HTTP exchange.

**Listener**\
A socket that waits for and accepts incoming connections.

**Port**\
A 16-bit number used with an IP address to identify a network service endpoint.

**Request target**\
The request-line value identifying the desired resource, often a path and query.

**Router**\
The component that maps method and target to application behavior.

**Socket**\
An operating-system abstraction for a network endpoint.

**TCP**\
A transport protocol providing a reliable, ordered byte stream.

**TLS**\
The security protocol that supplies encryption and authentication beneath HTTPS.
